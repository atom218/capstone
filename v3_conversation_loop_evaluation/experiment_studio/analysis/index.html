How the pairs were coded

New means the point did not appear anywhere in the matched baseline interview. More precise means the grounded answer gives an existing point a clearer condition, action or consequence. Repeated means the point already appears in the baseline, sometimes at another turn. Lost means the highlighted grounded answer omits a useful baseline detail at that turn.

These 12 cases were selected to cover gains, ties and declines, then coded from the interview text. The matrix describes this sample. Judge scores select the contrasts and the text determines the codes.
